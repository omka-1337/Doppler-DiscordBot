# Doppler plugins

The plugin catalogue for [Doppler](https://github.com/omka-1337/Doppler-DiscordBot).
Each top-level directory is one plugin; `index.json` is what the dashboard's
plugin browser reads.

Install these from the dashboard's **Plugins** tab rather than by copying
them in by hand — the broker records which source each plugin came from,
and that is what decides whether it is allowed to run sidecar containers.
